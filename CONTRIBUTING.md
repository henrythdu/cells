# Contributing to Cells

Issues and pull requests are welcome from anyone.

## Before you start

Run the checks:

```bash
pnpm run prepare
pnpm run typecheck
pnpm run test
```

All three must pass.

## Issues

Use one of the GitHub issue templates. State the bug or the request, and explain why it matters. Keep it short.

## Pull requests

Open a pull request at any time. Explain what changed and why. Keep the change small and focused.

You must understand the code you submit. Using an LLM to write it is fine.

A maintainer reviews every issue and every pull request, and gives the reason when a change does not fit the project.
